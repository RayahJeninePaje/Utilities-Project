# SIA Utilities
ITL313-18 SIA 2 Laboratory Final Term Mini Project

The application provides a dashboard for three utilities:

- **Fake Data Generator** — generates sample records and previews selected fields.
- **URL Shortener** — interface included; a shortening service is not connected.
- **SMS / Email** — interface included; a messaging service is not connected.

Run the app with `python main.py`. Sign in to open the dashboard and navigate
between the utilities.
